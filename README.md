# contract-multiplayer-fabric-archive

Archived decision records for the multiplayer fabric stack: rejected and superseded records, none of them a live design.

## What it is for

A record that stops being current moves here, at the path it had in the manuals, and leaves no stub behind. Current records live in `V-Sekai-fire/manuals-weftspun`, and RFD 2106 there explains why the archive is its own repository.

## Build and run

The records are plain Markdown; there is nothing to build.
